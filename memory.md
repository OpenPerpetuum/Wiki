### Map/zoom behavior spec (current, tested)
- wheel = zoom toward cursor; pinch = zoom about finger midpoint;
  drag = pan (handlers on the wrapper; pointer capture is lazy — only
  after a 2px move, so plain clicks still reach `<a>` elements in maps)
- max zoom-out s=1 (whole map visible); max zoom-in 8x
- pan limit: at least 25% of the viewport area stays covered by map
  content (two-pass clamp, shared budget both axes)
- ⟲ reset → `translate(0,0) scale(1)`
